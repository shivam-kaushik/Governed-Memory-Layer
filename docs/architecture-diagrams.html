Question 1

How do you keep one client's or team's memory from leaking into another's?

Never trust the caller. Identity comes from the session, the database query is built from that identity, and every vector hit is rechecked against the source of truth.

Honest limit: isolation is application-enforced logical isolation in a shared collection. Zero leaks in N trials is evidence, not a proof of impossibility.

Question 2

How does the agent fix or drop a memory that turns out wrong or expired?

Expiry is a gate at read time, not a cleanup job. Wrong memories are corrected into a new version or forgotten with a tombstone, and anything derived from them goes too.

Honest limit: forgetting means the agent cannot recover the memory from these stores. Atlas backups and outside copies are out of scope.

Question 3

How do you prove a memory changed the agent's behavior and didn't just fill the prompt?

Fork the same incident four ways. Only the memory block differs. If the action follows the memory, and flips when only the memory is flipped, memory caused it.

The four-arm experiment

One seed, run end to end

ArmMemory blockExpected resultRules out
R realCard with the seeded nonce poolAgent restarts the nonce pool (success ≥ 95%)—
Ø noneEmptyFails: a nonce cannot be guessedAgent solves it without memory
P placeboSame token count of unrelated fillerFails like ØAny long block helps
C counterfactualSame card, nonce swapped for another poolAgent restarts the other pool and nothing else changesCorrelation without cause
ControlsFresh nonce per seed. Prompt identical outside the memory block. Scorer sees a run id, never the arm.
ReportedCounts with samples, Wilson 95% intervals, R − P lower bound, targeted response, collateral stability.
Hard zerosHarmful adoption of expired, wrong-version, foreign, or forgotten memory. Shown as k / n.

Honest limit: the deterministic brain proves plumbing and governance, not model behavior. Model numbers come only from the LLM brain, and only if it was run. The proof shows changing memory changes the action, not the model's internal mechanism.
